# Chrome 웹 스토어 등록 정보

개발자 대시보드의 각 칸에 그대로 붙여 넣으면 됩니다.

## 스토어 등록정보 탭

**이름** (manifest에서 자동 입력)

```
카드 호버 for 하스스톤
```

**요약** (manifest의 description, 132자 이내)

```
하스스톤 패치 노트에서 카드, 전장 하수인, 장신구 이름에 마우스를 올리면 카드 이미지가 뜹니다. 비공식 팬 제작.
```

**설명**

```
패치 노트에 장신구랑 하수인 이름만 적혀 있고 이미지가 없어서, 하나씩 검색하다가 귀찮아서 만들었습니다.

이름에 마우스를 올리면 그 카드 이미지가 뜹니다. 기능은 이게 전부입니다.

일반 카드뿐 아니라 패치 노트에 이미지가 자주 빠지는 전장 하수인과 장신구도 보여 줍니다. "진흙 부식을 얻습니다"처럼 설명문 중간에 나오는 이름도 잡습니다. 같은 이름이 여러 장이면 같이 보여 주고, 패치 노트에 "(2단계)"라고 적혀 있으면 그 단계 것만 보여 줍니다.

사용법
- 설치하면 하스스톤 공식 사이트(hearthstone.blizzard.com)에서는 바로 됩니다.
- 인벤 같은 다른 사이트에서 쓰려면 그 사이트에서 확장 아이콘을 누르고 "이 사이트에서 사용"을 켜세요. 브라우저가 접근을 허용할지 한 번 묻습니다.

아직 안 되는 것
- 한글 이름만 됩니다.
- 이름 중간에 굵은 글씨나 링크가 걸려 있으면 못 알아봅니다.
- 패치 직후에는 새로 나온 것의 그림이 하루쯤 늦게 올라올 수 있습니다.

개인정보
아무것도 수집하지 않습니다. 켜 둔 곳에서만 동작하고, 이름 대조는 브라우저 안에서 끝납니다. 외부 요청은 HearthstoneJSON(hearthstonejson.com)에서 카드 데이터와 그림을 받아 오는 것뿐입니다.

팬이 만든 비공식 도구이고 Blizzard Entertainment와는 관련이 없습니다. Hearthstone은 Blizzard Entertainment, Inc.의 상표입니다.
```

## 개인 정보 보호 탭

**단일 목적 설명**

```
웹페이지에 적힌 하스스톤 카드 이름에 마우스를 올렸을 때 해당 카드의 이미지를 툴팁으로 보여 줍니다.
```

**storage 권한 사유**

```
카드 이름 목록(HearthstoneJSON에서 내려받은 공개 데이터)과 사용자가 확장 프로그램을 켠 사이트 목록을 저장합니다.
```

**activeTab 권한 사유**

```
사용자가 확장 프로그램 아이콘을 눌렀을 때 현재 탭의 호스트 이름을 읽어, 팝업에서 "이 사이트에서 사용" 설정을 표시하고 바꾸기 위해 사용합니다.
```

**scripting 권한 사유**

```
사용자가 허용한 사이트에만 카드 이름 인식 스크립트를 등록하고, 허용 직후 이미 열려 있는 해당 사이트 탭에 새로고침 없이 적용하기 위해 사용합니다.
```

**호스트 권한 사유**

```
hearthstone.blizzard.com: 공식 패치 노트와 소식 글에서 카드 이름에 마우스를 올렸을 때 카드 이미지를 보여 주기 위해 필요합니다. 마우스 포인터 아래 텍스트 최대 96자를 확장 프로그램 내부의 카드 이름 목록과 대조하는 데만 사용하며, 페이지 내용은 저장하거나 외부로 전송하지 않습니다.

선택적 호스트 권한(http/https): 설치 시에는 부여되지 않습니다. 사용자가 다른 사이트에서 팝업의 "이 사이트에서 사용"을 켤 때 그 사이트 하나에 대해서만 Chrome의 권한 요청 창으로 허용을 받습니다. 카드 이름은 커뮤니티나 블로그 등 어떤 사이트에도 나올 수 있어 목록을 미리 정할 수 없기 때문에 선택적 권한으로 선언했습니다.
```

**원격 코드 사용 여부**: 아니요 (내려받는 것은 JSON 데이터와 이미지뿐이며 실행 코드는 없음)

**데이터 사용**: 수집하는 사용자 데이터 항목 없음 — 모든 항목 체크 해제. 하단 3개 준수 선언은 모두 체크.

**개인정보처리방침 URL**: `https://umlog.github.io/hs-card-hover/PRIVACY.html`
